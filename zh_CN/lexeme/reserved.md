# Vanillang 保留字

这些词在 Vanillang 中禁用或保留给未来使用，不能用作标识符：

| 保留字                       | 描述                                 |
| ---------------------------- | ------------------------------------ |
| `lambda`                     | 用于匿名函数表达式                   |
| `command`                    | 用于声明内联命令块                   |
| `null`、`none`、`nil`        | Vanillang 不允许空值                 |
| `async`、`await`             | 用于异步控制                         |
| `generator`、`yield`、`from` | 用于生成器语法                       |
| `protected`                  | 用于对子类可见的访问控制             |
| `where`、`of`、`not`、`is`   | 保留备用                             |
| `abstract`                   | 暂时不打算加入抽象类，但未来可能加入 |
| `decorator`、`decorate`      | 用于声明和调用装饰器                 |
| `record`                     | 用于声明一个纯数据类，留作语法糖     |
