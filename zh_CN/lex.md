# Vanillang 基础词法定义

## 标识符

标识符是由开发者定义的数据类型名或变量名，应当满足以下命名规则：

* 标识符应当完全由字母、数字或下划线组成，区分大小写，且不能以数字开头，即必须满足正则表达式 `[A-Za-z_][A-Za-z0-9_]*`；
* 标识符不能是 Vanillang 的关键字或保留字；
* 标识符长度不能超过 255 个字符。

除了上述由语言定义的命名规则外，编译器会将以下符合特定格式的标识符保留用作特殊用途：

* 以两个下划线（`__`）开头的标识符，用于 ARC 代码生成，开发者不可在源代码中使用；
* 名为 `onLoad` 的函数将在数据包被加载时执行，该函数无参数和返回值，且不支持重载；
* 名为 `onTick` 的函数将在每个游戏刻执行，该函数无参数和返回值，且不支持重载。

我们推荐开发者在使用 Vanillang 时遵循以下规范：

* 类型名，例如类名、接口名等，使用 `PascalCase` 格式；
* 变量名、函数名使用 `camelCase` 格式；
* 编译时常量名、枚举值名使用 `UPPER_SNAKE_CASE` 格式。

## 字面量

字面量是表示特定值的字符串，不同类型的字面量遵循不同格式：

* 整型字面量（int 类型）

| 表示法 | 示例                                   | 备注                                                 |
| ------ | -------------------------------------- | ---------------------------------------------------- |
| 十进制 | `5`、`-9`、`16`、`1_000_000`、`-1_234` | 数位中间可以跟一个下划线；存储为值对应有符号数的补码 |

* 字节型字面量（byte 类型）

| 表示法     | 示例                        | 备注                                                                      |
| ---------- | --------------------------- | ------------------------------------------------------------------------- |
| 十进制     | `1B`、`-3b`、`42B`、`127b`  | 数位中间可以跟一个下划线；后缀 `b/B` 不能省略；存储为值对应有符号数的补码 |
| ASCII 字符 | `'a'`、`'B'`、`'1'`、`'\\'` | 使用单引号；存储为对应的 ASCII 码；支持使用转义符                         |

* 短整型字面量（short 类型）

| 表示法 | 示例                               | 备注                                                                                                               |
| ------ | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 十进制 | `2s`、`-32768S`、`256s`、`12_345S` | 数位中间可以跟一个下划线；后缀 `s/S` 不能省略；从右往左起每 3 个数位后可以跟一个下划线；存储为值对应有符号数的补码 |

* 长整型字面量（long 类型）

| 表示法 | 示例                                           | 备注                                                                                    |
| ------ | ---------------------------------------------- | --------------------------------------------------------------------------------------- |
| 十进制 | `-32768L`、`2147483648l`、`1_000_000_000_000L` | 数位中间可以跟一个下划线；后缀 `l/L` 不能省略，建议使用大写；存储为值对应有符号数的补码 |

* 二进制、八进制、十六进制字面量（类型取决于上下文）

| 表示法   | 示例              | 备注                                                                                                                |
| -------- | ----------------- | ------------------------------------------------------------------------------------------------------------------- |
| 二进制   | `0b10`、`0b10_11` | 数位中间可以跟一个下划线；前缀 `0b` 不能省略，其中 `b` 须为小写；存储为字面真值，高位补 0                           |
| 八进制   | `0o77`、`0o2_3`   | 数位中间可以跟一个下划线；前缀 `0o` 不能省略，其中 `o` 须为小写；存储为字面真值，高位补 0                           |
| 十六进制 | `0x7F`、`0xc0_c0` | 数位中间可以跟一个下划线；前缀 `0x` 不能省略，其中 `x` 须为小写；存储为字面真值，高位补 0；数位部分的字母大小写不限 |

* 布尔型字面量（bool 类型）

| 表示法 | 示例            | 备注               |
| ------ | --------------- | ------------------ |
| 布尔值 | `true`、`false` | 值为 true 或 false |

* 单精度浮点数（float 类型）

| 表示法     | 示例                                      | 备注                                                                                                                                               |
| ---------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 十进制小数 | `.1f`、`-1.5F`、`1.0f`、`2.f`、`3.14_15F` | 数位中间可以跟一个下划线；后缀 `f/F` 不能省略；整数或小数部分为 0 时可以省略不写；只有一个部分时小数点可以省略，也可以不省略                       |
| 科学记数法 | `1e3F`、`2.0e2f`、`3e-4`、`-2.e1F`        | 数位中间可以跟一个下划线；后缀 `f/F` 不能省略；小数部分为 0 时可以省略不写，此时小数点可以省略，也可以不省略；`e` 为小写，后面的整数表示 10 的幂次 |

* 双精度浮点数（double 类型）

| 表示法     | 示例                               | 备注                                                                                                                             |
| ---------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 十进制小数 | `.1`、`-1.5d`、`1.0d`、`2.`、`6.D` | 数位中间可以跟一个下划线；后缀 `d/D` 可以省略；小数部分为 0 时可以省略不写，小数点不可省略                                       |
| 科学记数法 | `1e3d`、`2.0e2`、`3e-4D`、`-2.e1`  | 数位中间可以跟一个下划线；后缀 `d/D` 可以省略；小数部分为 0 时可以省略不写，小数点不可省略；`e` 为小写，后面的整数表示 10 的幂次 |


* 字符串字面量（string 类型）

| 表示法       | 示例                      | 备注                                                                            |
| ------------ | ------------------------- | ------------------------------------------------------------------------------- |
| 普通字符串   | `"Hello, Vanillang!"`     | 使用双引号；支持转义符                                                          |
| 格式化字符串 | `f"the value is $(expr)"` | 以小写字母 `f` 开头；`$(expr)` 为插值语法；表达式 `expr` 必须可以被转换为字符串 |

* 数组字面量（Array\<T\> 类型）

| 表示法              | 示例                  | 备注                                                     |
| ------------------- | --------------------- | -------------------------------------------------------- |
| 数组通用表示        | [expr1, expr2, expr3] | 所有表达式必须具有相同类型                               |
| SNBT 整型数组表示   | [I; expr1, expr2]     | 匹配 SNBT 整型数组；所有表达式必须能被转换成 int 类型    |
| SNBT 字节型数组表示 | [B; expr1, expr2]     | 匹配 SNBT 字节数组；所有表达式必须能被转换成 byte 类型   |
| SNBT 长整型数组表示 | [L; expr1, expr2]     | 匹配 SNBT 长整型数组；所有表达式必须能被转换成 long 类型 |


* 列表字面量（List 类型）

| 表示法 | 示例                  | 备注                       |
| ------ | --------------------- | -------------------------- |
| 列表   | [expr1, expr2, expr3] | 每个表达式可以具有不同类型 |

* SNBT 字面量（Dict 类型和一切实现了 DataSerializable 接口的类型）

| 表示法 | 示例                                         | 备注                                                                                                                 |
| ------ | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| SNBT   | { key1: value1, key2: value2, key3: value3 } | 对于 DataSerializable 的实现类，键名必须与定义的属性名保持一致，值的类型必须可转化为属性类型；注意不支持无引号字符串 |

* 选择器字面量

| 表示法 | 示例                              | 备注                     |
| ------ | --------------------------------- | ------------------------ |
| 选择器 | `@a`、`@e[sort=nearest, limit=2]` | 遵循原版选择器的语法规范 |

* 范围字面量（Range 类型）

| 表示法 | 示例                                     | 备注                                                   |
| ------ | ---------------------------------------- | ------------------------------------------------------ |
| 范围   | `0..99`、`-10..-1`、`..2`、`..-5`、`1..` | 与原版范围表示保持一致，左边表示最小值，右边表示最大值 |

* 命名空间 ID 字面量（NamespaceId 类型）

| 表示法      | 示例                                                               | 备注               |
| ----------- | ------------------------------------------------------------------ | ------------------ |
| 命名空间 ID | `minecraft:stone`、`builder_and_redstoner:tick`、`foo:bar/baz/qux` | 与原版语法保持一致 |

* 正则表达式字面量（Regex 类型）

| 表示法     | 示例                | 备注                                |
| ---------- | ------------------- | ----------------------------------- |
| 正则表达式 | `r"^[A-Za-z0-9]+$"` | 以小写字母 `r` 开头，后接正则表达式 |
