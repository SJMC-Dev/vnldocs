# Vanillang 运算符

这些符号用于表示基本的运算操作，注意：除特殊的语法糖以外，Vanillang 不支持运算符重载

## 数学运算符

| 运算符 | 描述                                               |
| ------ | -------------------------------------------------- |
| `+`    | 二元运算符，用于两数相加，也可用于字符串拼接       |
| `-`    | 二元运算符，用于两数相减；一元运算符，用于数值取反 |
| `*`    | 二元运算符，用于两数相乘                           |
| `/`    | 二元运算符，用于两数相除，结果为双精度浮点数       |
| `//`   | 二元运算符，用于两数整除，结果为整数               |
| `%`    | 二元运算符，用于两数取模，结果符号与被除数相同     |
| `**`   | 二元运算符，用于幂运算，仅支持整数次幂             |
| `+=`   | 复合赋值运算符，等价于 `a = a + b`                 |
| `-=`   | 复合赋值运算符，等价于 `a = a - b`                 |
| `*=`   | 复合赋值运算符，等价于 `a = a * b`                 |
| `/=`   | 复合赋值运算符，等价于 `a = a / b`                 |
| `//=`  | 复合赋值运算符，等价于 `a = a // b`                |
| `%=`   | 复合赋值运算符，等价于 `a = a % b`                 |
| `**=`  | 复合赋值运算符，等价于 `a = a ** b`                |

## 赋值运算符

| 运算符 | 描述                                                                            |
| ------ | ------------------------------------------------------------------------------- |
| `=`    | 赋值运算符，将右值赋给左值                                                      |
| `??=`  | 空值合并赋值运算符，左值需为 Optional\<T\> 类型，当左值为 none 时将右值赋给左值 |

## 比较运算符

| 运算符 | 描述                                       |
| ------ | ------------------------------------------ |
| `==`   | 等于运算符，比较两个值是否相等             |
| `!=`   | 不等于运算符，比较两个值是否不相           |
| `<`    | 小于运算符，比较左值是否小于右值           |
| `>`    | 大于运算符，比较左值是否大于右值           |
| `<=`   | 小于等于运算符，比较左值是否小于或等于右值 |
| `>=`   | 大于等于运算符，比较左值是否大于或等于右值 |

## 逻辑运算符

| 运算符 | 描述                                             |
| ------ | ------------------------------------------------ |
| `&&`   | 逻辑与运算符，左值和右值都为真时结果为真         |
| `\|\|` | 逻辑或运算符，左值和右值有一个为真时结果为真     |
| `!`    | 逻辑非运算符，值为真时结果为假，值为假时结果为真 |

## 位运算符

| 运算符 | 描述                                                                   |
| ------ | ---------------------------------------------------------------------- |
| `&`    | 位与运算符，对两个整数的每一位执行逻辑与操作                           |
| `\|`   | 位或运算符，对两个整数的每一位执行逻辑或操作                           |
| `^`    | 位异或运算符，对两个整数的每一位执行逻辑异或操作                       |
| `~`    | 位非运算符，对一个整数的每一位执行逻辑非操作                           |
| `<<`   | 算术左移运算符，将一个整数的二进制表示向左移动指定的位数               |
| `>>`   | 算术右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补符号位 |
| `>>>`  | 逻辑右移运算符，将一个整数的二进制表示向右移动指定的位数，高位补 0     |
| `&=`   | 位与赋值运算符，等价于 `a = a & b`                                     |
| `\|=`  | 位或赋值运算符，等价于 `a = a \| b`                                    |
| `^=`   | 位异或赋值运算符，等价于 `a = a ^ b`                                   |
| `<<=`  | 算术左移赋值运算符，等价于 `a = a << b`                                |
| `>>=`  | 算术右移赋值运算符，等价于 `a = a >> b`                                |
| `>>>=` | 逻辑右移赋值运算符，等价于 `a = a >>> b`                               |

## 其他运算符

| 运算符 | 描述                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| `.`    | 成员访问运算符，用于访问对象的属性或方法；包访问运算符，用于访问子包、模块或标识符                                   |
| `?.`   | 安全成员访问运算符，用于访问 Optional\<T\> 对象的属性或方法，如果对象为 none 则返回 none 而不是抛出异常              |
| `[]`   | 索引访问运算符，用于访问数组、列表或字典的元素；切片访问运算符，用于访问字符串的子串                                 |
| `()`   | 函数调用运算符，用于调用函数或方法                                                                                   |
| `?:`   | 条件表达式运算符，根据条件表达式的值选择返回结果                                                                     |
| `??`   | 空值合并运算符，当左值不为 none 时返回左值，否则返回右值，左值需为 Optional\<T\> 类型，右值不能为 Optional\<T\> 类型 |
| `..`   | 范围运算符，用于生成一个包含起始和结束值的 Range 结构                                                                |
| `...`  | Rest 参数或 Spread 操作符                                                                                            |
